# Project Title
Water Potability Prediction using Machine Learning
# Description
This project focuses on predicting whether water is safe for drinking (potable) or not using machine learning techniques. It analyzes various chemical properties of water such as pH, hardness, solids, and more to make predictions.
# Objective
The goal of this project is to:

Build a model that classifies water as potable or non-potable
Help in ensuring safe drinking water using data-driven insights
# Dataset
The dataset contains water quality metrics like:
pH
Hardness
Solids
Chloramines
Sulfate
Conductivity
Organic Carbon
Trihalomethanes
Turbidity
Target variable: Potability (0 = Not Safe, 1 = Safe)
# Technologies Used
Python
Pandas
NumPy
Matplotlib / Seaborn
Scikit-learn
# Machine Learning Models

XG Boost
SVM
Decision Tree
Random Forest
K-Nearest Neighbors
# Workflow
Data Collection
Data Preprocessing (handling missing values, normalization)
Exploratory Data Analysis (EDA)
Model Training
Model Evaluation
Prediction
# Results
Best performing Model: SVM model
